# Rock Paper Scissors Game
A simple and interactive Rock Paper Scissors game developed using Python and Tkinter. The game allows the user to play against the computer by selecting Rock, Paper, or Scissors.
The computer randomly selects its choice, and the winner is decided based on the game rules. The application also keeps track of the scores and provides an option to reset the game.
### Project Structure
- **main.py:** Connects the game logic and user interface.
- **game_logic.py:** Handles computer choices and winner decisions.
- **ui.py:** Creates the graphical interface, buttons, and score display.
### Technologies Used
- Python
- Tkinter
- Random Module
### Features
- User-friendly graphical interface.
- Play against the computer.
- Random computer selection.
- Displays game results.
- Tracks player and computer scores.
- Reset game option.
